Installation

The public Chrome Web Store launch is coming soon. Until then, use a verified release artifact or build from source.

  1. Download and extract a COMPANION release package from GitHub.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked.
  5. Choose the extracted folder that contains manifest.json.
  6. Open or reload Claude.ai or ChatGPT.com.

For source builds and release verification, follow the repository README and release notes.

Usage information is blank

  • Confirm you are signed in to a supported Claude or ChatGPT web surface.
  • Reload the provider tab after installing or updating the extension.
  • Open the extension popup and confirm the active provider context.
  • Remember that COMPANION does not invent missing counters. A blank value may mean the provider exposes no supported native numeric field to that account or surface.
  • Provider changes can temporarily require an extension update.

Lifejacket did not shorten a prompt

This can be correct behavior. Lifejacket keeps the original when a candidate is longer, removes too much content, changes protected spans, has poor tokenizer coverage, or encounters a model, validation, or runtime failure. Prompt compression and reply brevity are separate controls.

A file did not convert correctly

Confirm the file is supported and within the current size limit. Scanned documents require OCR, which COMPANION does not include. Complex tables, tracked changes, embedded media, macros, annotations, and unusual document structures may not survive conversion perfectly. Review the Markdown before sending it.

Reset or remove local data

Use the Data & privacy section in COMPANION settings to clear local history and operational caches. Uninstalling the extension removes browser-managed COMPANION storage. There is no remote account to delete.

Report a bug or request a feature

Use GitHub Issues for reproducible non-sensitive bugs and feature requests. Include the COMPANION version, browser version, provider surface, expected behavior, actual behavior, and minimal reproduction steps.

Send security-sensitive reports to zgbrenner@gmail.com. Never include passwords, cookies, account tokens, private prompts, or private files.
