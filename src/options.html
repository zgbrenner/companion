Enterprise limit (from Claude.ai)

Reads Claude's monthly usage-credit spend limit directly — not an estimate. Uses an undocumented endpoint that Anthropic could change without notice; if it stops working, this section shows an error and the chat estimate still works.

This is the expected per-employee cap, used only as an advisory comparison — if Claude returns a different cap it's still shown (with a note), not hidden. Only values that look like a cents/dollars unit mismatch get rejected.

With an Organization ID set, that ID is used directly. Clear the cache only matters if the Organization ID field is blank.
