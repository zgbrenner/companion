Data & privacy

Everything stays on this device.

What is stored
  • Stored locally: settings, Claude daily spend totals, bounded OpenAI usage snapshots, and small provider caches.
  • Never stored: prompt or reply text, file contents, passwords, login cookies, or raw provider account payloads.
  • No analytics: COMPANION has no telemetry, tracking, or developer backend.
