About these numbers

Every dollar figure is read from Claude's own usage-credit counter — real account data, accurate to the cent, never an estimate. Session and daily spend cover all of your Claude activity in that window (any tab or device), not one specific chat. Token figures are the only derived numbers: a range computed from real dollars using current Anthropic pricing and a documented input/output/caching mix.
